PROJECTS

ClassHub 🎓 - Secure Class Portal classhub2.vercel.app • LIVE

Problem: WhatsApp buries slides and past questions. Solution: one searchable portal. Students register once, then browse materials by course and week, past questions, announcements, the real timetable with a live teaching-week banner, deadline countdowns, and send requests. Reps get an upload center for files or Drive links, pinned announcements, deletion, "seen by" counts and one-tap Share to WhatsApp.

Security: a Postgres trigger checks each rep's index and secret code at signup, and row level security plus storage policies are enforced on the server, so only reps can post or delete. Output is escaped against script injection.

Stack: HTML, CSS, Vanilla JS, Supabase (Auth, Postgres, Storage, RLS), Vercel, wa.me API.
